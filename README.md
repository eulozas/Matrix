# Matrix

**Matrix** - библиотека для работы с числовыми матрицами на языке C.  
Проект реализует основные операции с матрицами, используемые в программировании, вычислительных задачах и компьютерной графике.

## Реализованные возможности

- Создание и очистка матриц (`s21_create_matrix`, `s21_remove_matrix`);
- Сравнение матриц с точностью до 6 знаков (`s21_eq_matrix`);
- Арифметические операции:
  - Сложение (`s21_sum_matrix`)
  - Вычитание (`s21_sub_matrix`)
  - Умножение матрицы на число (`s21_mult_number`)
  - Умножение матриц (`s21_mult_matrix`)
- Транспонирование (`s21_transpose`);
- Вычисление миноров и матрицы алгебраических дополнений (`s21_calc_complements`);
- Вычисление определителя (`s21_determinant`);
- Поиск обратной матрицы (`s21_inverse_matrix`);
- Проверка корректности матриц и обработка ошибок:
  - 0 OK
  - 1 некорректная матрица
  - 2 ошибка вычисления (несовпадающие размеры и т.д.)
